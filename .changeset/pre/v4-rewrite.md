v4 is a rewrite of the plugin for Better Auth 1.7: a sign-up gate that covers every sign-up method, invite codes, Guests (users with no account), referrals, status links, manager endpoints and a typed client (`better-auth-waitlist/client`). It stores entries in a new `waitlistEntry` model and has no automatic migration from v3; see "Upgrading from v3" in the README.
